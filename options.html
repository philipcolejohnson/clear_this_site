Application

Storage

Data saved by websites for settings, preferences, and temporary information. These may contain login data.
Database storage for web apps to save large amounts of structured data locally.
Older database storage. Most modern sites don't use this anymore.
Small bits of data used to remember your login status, shopping cart, or site preferences. This does not delete third-party cookies.
Files that websites store locally, like downloaded documents or cached media.

Cache

Resources saved by a site for offline use, like pages, images, and scripts.
Cached files (images, scripts, stylesheets) saved on your computer by your browser to speed up page loading.

Additional options

Clears the browser's cached files for all websites. This does not affect application or storage data for other sites.
